Public register / privacy

What this site collects.

Critical Mass Labs publishes this public register at criticalmassforge.com. The page itself does not use analytics cookies and does not require an account.

If you send a question or comment, the note — including your reply address, optional name, and the program you selected — is delivered to the studio mailbox at admin@asymmetria.io so we can respond. Those messages are not published back onto the site.

Hosting and delivery providers (for example GitHub Pages and the form relay) may process technical request data such as IP address and user agent as part of ordinary web operation.

Program sites linked from this register, including Asymmetry, have their own notices. For Asymmetry specifically, see asymmetria.io/privacy.
